# Helix Landing

Marketing site for **Helix** — the atomic work-breakdown orchestrator for AI coding agents.

This is a separate Next.js project from the upstream Helix product. It is intended to be a polished, brand-forward marketing surface that introduces the product, demonstrates capabilities, and drives visitors to the GitHub repo and live deployment.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- TypeScript 5

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

One-click deploy to Vercel — `vercel` from the project root, or import this repo in the Vercel dashboard.
