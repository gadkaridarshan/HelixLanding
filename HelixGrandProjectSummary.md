# Grand Project Summary

The Helix AI Orchestrator landing page is a Next.js 14 (App Router) + TypeScript + Tailwind site scaffolded at the repo root with Inter via `next/font`, brand tokens defined in `lib/brand.ts` and `@theme` in `app/globals.css`, and shared UI/layout primitives under `components/ui/` and `components/layout/` (USER-179000), then re-themed with a polished gradient/grid/noise system and a section composition root in `components/landing/Sections.tsx` (USER-986000). All marketing sections are built and compose into one conversion-oriented page at `app/page.tsx`: Hero (`components/landing/hero/`, `app/components/sections/Hero.tsx`), HowItWorks (`components/landing/how-it-works/`, `app/components/sections/HowItWorks.tsx`), Features (`components/landing/features/`, `app/components/sections/Features.tsx`), Personas + StatsBar + FinalCTA (`components/landing/personas/`, `app/components/sections/Personas.tsx`, `StatsBar.tsx`, `FinalCTA.tsx`), Social Proof (`components/landing/social-proof/`), FAQ accordion (`components/landing/faq/`, `app/components/sections/FAQ.tsx`, `content/faq.json`), closing CTA (`components/landing/cta/`, `content/cta.json`), and footer with Vercel deploy reference (`components/landing/footer/`); Vercel readiness is configured via `vercel.json`, `.vercelignore`, and `.gitignore` (USER-993000, USER-347000, USER-212100, USER-212000, USER-956000, USER-349000). An earlier `@/app/components/sections/Hero` import-resolution diagnostic was reconciled so a single canonical section path resolves cleanly (USER-348000, USER-217000).
