# Grand Project Summary

The Helix landing page project is built on a Next.js 14 App Router + TypeScript + Tailwind scaffold (USER-179000, USER-969000, USER-986000) with a unified brand system — Inter + JetBrains Mono via next/font, ink/brand/aurora tokens in `lib/brand.ts` and `lib/theme.ts`, and a polished gradient + grid + noise background in `app/globals.css`. Marketing sections ship as self-contained components: Hero, HowItWorks, and Features in `components/Hero.tsx`, `components/Features.tsx`, `components/HowItWorks.tsx` (also under `app/components/sections/`); Personas, SocialProof, FAQ, CTA, and Footer in `components/Personas.tsx`, `components/SocialProof.tsx`, `components/FAQ.tsx`, `components/CTA.tsx`, `components/Footer.tsx`, plus `components/ui/accordion.tsx`. Page assembly lives in `app/page.tsx` and `app/layout.tsx` with Vercel config in `vercel.json`, `.vercelignore`, and `.gitignore`. Copy corrections (USER-616000 through USER-574000) now clearly distinguish the Vercel link as a reference site rather than the live deployment. Content for the marketing sections is sourced from `content/faq.json`, `content/cta.json`, `content/hero.json`, `content/how-it-works.json`, `content/features.json`, `content/personas.json`, and `content/social-proof.json`, with assets under `assets/hero/**`, `assets/features/**`, `assets/personas/**`, and `public/**`. One card (USER-308000, Personas / social proof / FAQ / CTA) remains in_progress to finalize that bottom-of-page composition, after which the page should type-check, build, and be deployable to Vercel.
