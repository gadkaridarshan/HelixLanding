# Grand Project Summary

The Helix AI Orchestrator landing page is delivered as a fresh, separately deployable Next.js project (distinct from the reference at helix-ai-orchestrator.vercel.app) that composes Hero, HowItWorks, Features, Personas, SocialProof, StatsBar, FAQ, FinalCTA, and Footer into a single conversion-oriented page, implemented across `app/page.tsx`, `app/layout.tsx`, `app/globals.css`, `components/landing/**`, and `public/**`. The brand foundation (`lib/brand.ts`, `@theme` in `globals.css`, the gradient/grid/noise background system, and the section composition root `components/landing/Sections.tsx`) shipped via USER-986000 and refined by USER-179000 anchors every downstream component, which live under both `components/sections/**` and the newer `components/landing/{hero,how-it-works,features,personas,social-proof,faq,cta,footer}/**` trees. Marketing copy and structure are split into data-driven JSON (`content/hero.json`, `content/how-it-works.json`, `content/features.json`, `content/personas.json`, `content/social-proof.json`, `content/faq.json`, `content/cta.json`) and a dedicated Use Cases band sits in `components/UseCases.tsx` + `components/UseCases.module.css` (USER-468000). Vercel deployment and SEO are wired via `vercel.json`, `.vercelignore`, `.gitignore`, `app/sitemap.ts`, `app/robots.ts`, `app/icon.tsx`, `app/apple-icon.tsx`, `app/opengraph-image.tsx`, `public/favicon.ico`, and `public/og/**`.
