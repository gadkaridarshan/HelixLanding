# Grand Project Summary

The Helix AI orchestrator landing page is a Vercel-deployable Next.js 14 (App Router) + TypeScript + Tailwind site that markets the atomic work-breakdown orchestrator to every persona on the reference site. The foundation ships in `app/layout.tsx`, `app/globals.css`, `lib/brand.ts`, `app/fonts.ts`, and `lib/theme.ts` (typography via Inter + JetBrains Mono, polished gradient/grid/noise background, shared theme tokens, reusable atoms in `components/ui/`, navbar/footer in `components/layout/`). Top-of-page marketing lives in `components/Hero.tsx`, `components/Features.tsx`, and `components/HowItWorks.tsx`, with a polished Hero (headline + subhead + dual CTA to live site and GitHub, animated gradient mesh and mock board preview), a 3×2 Features grid (atomic planning, parallelization gating, language-aware protected paths, quality bar, GIVEN/WHEN/THEN acceptance criteria), and a 3–4 step HowItWorks numbered flow with SVG diagrams. Bottom-of-page trust and conversion is built in `components/Personas.tsx`, `components/SocialProof.tsx`, `components/FAQ.tsx`, `components/CTA.tsx`, and `components/Footer.tsx` (with `components/ui/accordion.tsx`), covering Developer / Product Manager / Founder / Enterprise personas, GitHub + reference-site badges, an accessible FAQ accordion, a full-bleed FinalCTA, and a minimal footer with copyright and dual links. A long thread of copy-correctness cards (USER-616000 → USER-574000) has fully relabeled https://helix-ai-orchestrator.vercel.app/ as the reference site so the landing page itself reads as the live destination, and `app/page.tsx` composes Hero → HowItWorks → Features → Personas → StatsBar → FAQ → FinalCTA between Navbar and Footer for Vercel deployment.
